# 🌤️ Weather App

Welcome to the Weather App! This application provides current weather information, hourly forecasts, and weekly forecasts for any city you enter. Built with HTML, CSS, and JavaScript, it features a user-friendly interface and real-time weather updates.

## 🖼️ Preview

![Weather App Screenshot](https://github.com/Raghavkumarprabhakar/Web-Projects/blob/main/Weather%20Forcast/images/Screenshot%202024-09-07%20134719.png)

## 📋 Features

- 🌐 **City Search:** Enter any city name to get the current weather.
- 🌦️ **Current Weather:** Displays temperature, weather conditions, humidity, and wind speed.
- ⏳ **Hourly Forecast:** Provides weather information for the next 24 hours.
- 📅 **Weekly Forecast:** Shows weather predictions for the next 7 days.

## Directory Structure

- **`index.html`**: The main HTML file for the application.
- **`styles.css`**: The CSS file containing styles for the application.
- **`script.js`**: The JavaScript file for interactivity and dynamic content.
